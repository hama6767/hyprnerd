# Third-party provenance

`hyprnerd` contains a port of existing KooL dotfiles and a personal reference theme. Copyright remains with the original authors. GPL-3.0-or-later covers the integration code and GPL-derived configuration, not a blanket relicensing of every bundled asset.

| Component | Source / licence information |
| --- | --- |
| Lua configuration and desktop scripts | [LinuxBeginnings/Hyprland-Dots](https://github.com/LinuxBeginnings/Hyprland-Dots/tree/170b69b846b1cd92ebc6d81c17393e17bed8d416), GPL-3.0; original notices retained |
| Reference Waybar/Rofi/Kitty appearance | [JaKooLit/Hyprland-Dots](https://github.com/JaKooLit/Hyprland-Dots), personal v2.3.17 reference configuration |
| Flat Remix icons | [daniruiz/flat-remix](https://github.com/daniruiz/flat-remix), licence in `licenses/flat-remix/` |
| Noto, Adwaita, Fira Code, JetBrains Mono | Font licence notices retained under `licenses/` |
| Nerd Font patches | [ryanoasis/nerd-fonts](https://github.com/ryanoasis/nerd-fonts); font-specific notices retained |
| Victor Mono | [rubjo/victor-mono](https://github.com/rubjo/victor-mono), SIL Open Font License |
| Kvantum theme | [catppuccin/kvantum](https://github.com/catppuccin/kvantum), original theme assets |
| Kali-Dark | Kali desktop theme copied from the reference environment; original theme metadata retained |
| Quickshell Hyprview | Licence retained in its source directory |
| Wallpapers and power-menu artwork | User-provided reference wallpaper and upstream KooL artwork; original authors retain copyright. The code licence does not grant additional rights to these images. |

Ubuntu Kvantum/qt5ct packages are downloaded by exact URL and checksum; package binaries are excluded from Git and release archives. Package source and licence information remain available from Ubuntu and the Papirus PPA named in `dependencies.lock.json`.
